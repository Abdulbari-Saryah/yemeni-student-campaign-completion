# ختام حملة دعم الطالب اليمني في الصين

موقع مستقل لتجهيز إعلان اكتمال التبرعات مع بيان المبالغ باليوان الصيني. يتضمن الإعلان صورة الحملة المموّهة ورسالة شكر ودعاء لكل من تبرّع أو شارك النداء أو دعا للطالب وأهله.

- أدخل إجمالي كل قناة. المبلغ المستلم فعليًا هو مجموع اتحاد الطلاب وويشات وأليباي والتحويل البنكي. اترك خانة البنك فارغة عند غياب الرقم، أو أدخل صفرًا إذا تأكّدت من عدم وجود تحويلات.
- ضع في خانة التعهدات المبالغ التي لم تُحصّل بعد. عند تحصيل تعهّد، أضف المبلغ إلى القناة التي استلمته واخصمه من التعهدات.
- يظهر ختم **اكتمل المبلغ** ويتاح تنزيل الإعلان بصيغة PNG عند بلوغ المستلم فعليًا هدف الحملة. يعرض البيان المتبقّي قبل الاكتمال أو الفائض بعده.
- تُحفظ مسودة الأرقام في متصفحك. لإظهار الأرقام لجميع الزوار نزّل ملف الأرقام، ثم ارفع `campaign.js` إلى جذر هذا المستودع واحفظ التغيير على فرع `main`. ستظهر القيم الجديدة بعد نشر GitHub Pages.

لتشغيل الموقع محليًا، نفّذ `python -m http.server 8000` داخل مجلد المشروع، ثم افتح [الموقع المحلي](http://localhost:8000/).
